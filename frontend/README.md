# Crime Intelligence Frontend

React dashboard for the crime intelligence backend.

## Setup

1. Copy `.env.example` to `.env`.
2. Set `VITE_API_BASE_URL` to the backend API URL.
3. Set `VITE_GOOGLE_MAPS_API_KEY` to a Google Maps JavaScript API key.
4. Install and run:

```bash
npm install
npm run dev
```

## Screens

- District map and police-station drill-down using Google Maps.
- Spatiotemporal cluster layer for hotspot detection.
- Emerging trend alert panel.
- React Flow link analysis graph with editable nodes and relationship edges.
- Predictive risk and anomaly dashboard.
- Non-destructive case similarity workbench for investigator statements.
